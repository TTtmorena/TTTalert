## Features

TTTalert is a proactive alert skill designed specifically for the Bankr ecosystem on Base & Robinhood Chain.

| Capability                    | Description                                              | Status     |
|-------------------------------|----------------------------------------------------------|------------|
| **Fee Claim Alert**           | Notify when claimable fees reach threshold (default 0.01 WETH) | Advanced   |
| **Volume Spike Detection**    | Real-time detection of significant volume increases      | Real-time  |
| **Momentum Shift Alert**      | Detect changes in fee generation & price momentum        | Intelligent|
| **Price Move Alert**          | Customizable price change notifications                  | Supported  |
| **Multi-Token Watchlist**     | Monitor multiple tokens at once                          | Complete   |
| **Custom Thresholds**         | Fully adjustable alert levels                            | Flexible   |
| **Risk Warnings**             | Liquidity health & fee sustainability alerts             | Advanced   |
| **Quick Status & Digest**     | Instant overview of all active alerts                    | Smart      |

## Install

Install directly into your Bankr agent:

```bash
install the skill at https://github.com/TTtmorena/TTTalert
```

After installation, the skill activates automatically when you ask about alerts, notifications, watchlist, fee claims, volume spikes, or TTTalert.
